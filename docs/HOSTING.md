# Hosting the game

Release layout (`carma2web-<version>.zip`):

```
site/      the web site (add the game data with tools/make_data.py)
server/    network relay server and its guide (server/README.md)
tools/     make_data.py / make_data.cmd — game data packer
GAME_FILES.md
```

## The site

After running the packer, upload **the whole contents of `site/`** (including the hidden `.htaccess` file) to the root of your web site or to any subfolder. The game opens via `index.html`.

| File | What |
|------|------|
| `index.html` | Game page |
| `carma2hy.js`, `carma2hy.wasm` | The runtime: x86 emulator + JIT, Glide/WebGL, sound, input, network |
| `carma2data.js` | Game data loader (generated by `make_data.py`) |
| `carma2web.data.000` … `.009` | Game data, 20 MB parts, ~200 MB in total (generated by `make_data.py`) |
| `config.js` | Network relay address (see below) |
| `music/` | CD music tracks (optional, see [GAME_FILES.md](GAME_FILES.md#music-optional)) |
| `.htaccess` | MIME types and caching for Apache |

Host requirements:

* `.wasm` files must be served as `application/wasm`. For Apache this is in `.htaccess`, for nginx see `server/nginx.conf.example`. Most modern hosts do it by default.
* The site must be opened over `http://` or `https://`. Double-clicking `index.html` on disk will not work.
* The host's per-file size limit must be at least 21 MB.

Static hosts such as GitHub Pages, Cloudflare Pages, Netlify or any shared web hosting work for single player.

The game data (~200 MB) is downloaded on the first visit; after that the browser takes it from its cache. Saved games, settings and the list of JIT-compiled code are kept in the player's browser.

## Network game

Needs the relay from `server/` — see [server/README.md](../server/README.md). In short:

* If the site is served by `relay.js` itself, or by nginx proxying `/net`, leave `config.js` as it is.
* If the site is on a static host and the relay runs elsewhere, put its address into `config.js`:

  ```js
  window.CARMA2_RELAY = 'wss://relay.example.com/net';
  ```

## URL parameters

| Parameter | Effect |
|----------|------------|
| `?wide=0` | 4:3 picture instead of widescreen |
| `?scale=1..4` | Internal resolution (default 2) |
| `?msaa=0..8` | Anti-aliasing (default 4) |
| `?touch=1` / `?touch=0` | Force touch controls on / off |
| `?room=name` | Network game room |
| `?name=Name` | Default network name |
| `?stats=1` | Show FPS and emulator statistics |
